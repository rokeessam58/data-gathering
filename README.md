# 자료 수합 도우미

선생님들께 자료를 수집하고, 응답을 구글 시트에 쌓아 엑셀로 내려받는 웹앱입니다.
화면은 이 저장소(GitHub Pages)에서 제공하고, 데이터는 **각 관리자의 구글 계정**(Apps Script + 스프레드시트)에 저장됩니다.
서버 주소는 코드에 들어 있지 않으므로 누구나 자기 구글 계정으로 연결해 쓸 수 있습니다.

## 관리자 설정 (처음 한 번)

1. 새 구글 스프레드시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. [`gas/Code.gs`](gas/Code.gs) 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱**: 실행 계정 "나", 액세스 권한 "모든 사용자"로 배포하고 권한을 승인합니다.
4. 앱 주소 뒤에 `?admin`을 붙여 접속하고, 웹 앱 URL(`…/exec`)을 입력합니다. 주소는 접속 가능한지 확인한 뒤 이 브라우저에 저장됩니다.
5. 서버에 관리자 비밀번호가 아직 없으면 **최초 1회 비밀번호 설정 화면**이 나옵니다. 8자 이상으로 정하고 한 번 더 입력해 확인합니다.
   - 설정은 비밀번호가 없을 때만 가능하고, 한 번 정하면 웹에서는 바꿀 수 없습니다. 바꾸려면 Apps Script의 **프로젝트 설정 → 스크립트 속성**에서 `ADMIN_PASSWORD` 값을 직접 수정하세요.
   - 배포 직후 바로 접속해서 정하세요. 비밀번호를 정하기 전에는 서버 주소를 아는 사람이 먼저 정할 수 있습니다.
   - 원한다면 배포 전에 스크립트 속성에 `ADMIN_PASSWORD`를 직접 넣어 두어도 됩니다. 이 경우 설정 화면은 나오지 않습니다.
6. 서버에 **자료 요구자** 정보가 아직 없으면(이름도, 이름 없는 비공개 설정도 없으면) 로그인 화면에 **자료 요구자 이름**(선택: **비공개**) 입력칸이 함께 나옵니다. 이름은 선생님 첫 화면에 `요구자 : 홍길동 선생님`으로 표시되고, 비공개를 체크하면 `요구자 : 비공개`로 표시되며 이름은 서버에서 내려가지 않습니다. 한 번 입력한 뒤에는 로그인할 때 **비밀번호 칸만** 나옵니다.
7. 로그인한 뒤 화면 오른쪽 위의 **메뉴(☰)**에 마우스를 올리면 **마이페이지**, 서버 변경, 로그아웃이 나옵니다. **마이페이지**는 비밀번호를 한 번 더 입력해야 열리며, 자료 요구자 이름 변경, 비공개 여부 변경, **관리자 비밀번호 변경**을 할 수 있습니다.

`Code.gs`를 고친 뒤에는 **배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다. (URL은 그대로)

## 링크 구조

| 용도 | 형태 |
|---|---|
| 관리자 | `…/?admin` (서버 주소는 처음 한 번 직접 입력) |
| 선생님: 자료 목록 | `…/?g=배포ID` |
| 선생님: 특정 자료 | `…/?g=배포ID&f=자료코드` |

선생님용 링크는 관리자 화면의 **링크 복사** 버튼으로 만듭니다.
관리자 화면은 링크로 전달된 서버 주소를 무시합니다. (비밀번호가 다른 서버로 전송되는 것을 막기 위함)

## 주의

- 응답에는 선생님들의 개인정보가 포함될 수 있습니다. 수집 목적과 보관 기간은 관리자가 책임지고 관리하세요.
- 링크를 아는 사람은 누구나 제출할 수 있습니다. 관리자 기능은 비밀번호로 보호됩니다.
- 이 저장소에는 개인 서버 주소나 비밀번호를 올리지 마세요.

## 보안

- **로그인 잠금**: 관리자 비밀번호를 5번 틀리면 5분 동안 모든 관리자 요청이 막힙니다. 웹 앱은 요청한 기기를 구분할 수 없어서 **서버 전체에 하나의 잠금**이 걸립니다. 다른 컴퓨터에서 틀려도 잠기고, 잠겨 있는 동안에는 맞는 비밀번호도 거부됩니다. 마지막 실패 후 10분이 지나면 틀린 횟수는 다시 셉니다. (Code.gs 상단의 LOCK_MAX_FAILS, LOCK_MINUTES, FAIL_WINDOW_MINUTES)
- **외부 스크립트 검증**: ExcelJS와 JSZip은 index.html에서 무결성(SRI) 값을 지정해 불러옵니다. 내용이 바뀌면 브라우저가 실행하지 않습니다. 버전을 올릴 때는 새 파일의 sha384 값으로 함께 바꾸세요.
- **가짜 링크 주의**: 이 앱은 누구나 자기 서버를 연결할 수 있어서, 선생님 화면에는 "자료 요구자에게 직접 받은 링크인지 확인하라"는 안내가 표시됩니다.
- 스프레드시트를 **편집자**로 공유하면 그 사람이 Apps Script에서 ADMIN_PASSWORD를 볼 수 있습니다. 공유는 보기 권한으로만 하세요.
